# Contract surfaces

Names that other parts of the system depend on. Renaming any of them breaks a caller in another slice — change them only together with every listed user, and in a new additive migration for database names.

## Database (`supabase/migrations/20261110210825_flashcard_data_contract.sql`, `20261110221827_flashcard_key_folding.sql`, `20261110224353_proposal_outcomes.sql`, `20261111144401_profiles.sql`, `20261111184853_manual_outcomes.sql`, `20261111214624_flashcard_tag_edit.sql`, `20261113200854_review_session.sql`)

| Name                                                                              | Contract                                                                                                                                                                                                                                  | Relied on by |

| `listFlashcards(client, { offset, limit })`                                       | `FlashcardPage`: up to `limit` cards with tags, ordered `created_at desc, id asc` (total; edits cannot move a card, so offset paging stays exact); fetches `limit + 1` rows via `.range()` to set `hasMore`. `COLLECTION_PAGE_SIZE = 50`. | S-05         |
