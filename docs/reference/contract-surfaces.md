# Contract surfaces

Names that other parts of the system depend on. Renaming any of them breaks a caller in another slice — change them only together with every listed user, and in a new additive migration for database names.

## Database (`supabase/migrations/20261110210825_flashcard_data_contract.sql`, `20261110221827_flashcard_key_folding.sql`, `20261110224353_proposal_outcomes.sql`, `20261111144401_profiles.sql`)

| Name                                                                                                           | Kind     | Contract                                                                                                                                                                                                                                                                                                                                                                                                                                              | Relied on by           |
| -------------------------------------------------------------------------------------------------------------- | -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------- |
| `public.flashcards`                                                                                            | table    | One row per word per user. Columns: `word`, `word_key` (generated), `translation`, `additional_meanings text[]`, `example_sentence`, `cefr` (A1–C2 or null), timestamps.                                                                                                                                                                                                                                                                              | S-01, S-04, S-05, S-06 |
| `public.tags`                                                                                                  | table    | One row per tag name per user. Columns: `name` (as first typed), `name_key` (generated).                                                                                                                                                                                                                                                                                                                                                              | S-01, S-05, S-06       |
| `public.flashcard_tags`                                                                                        | table    | Card ↔ tag links; composite foreign keys guarantee both belong to the same user. Index on `tag_id` for review by tag.                                                                                                                                                                                                                                                                                                                                 | S-05, S-06             |
| `word_key` / `name_key`                                                                                        | rule     | `lower(btrim(regexp_replace(x, '\s+', ' ', 'g')))` — every whitespace run (incl. tabs, newlines) collapsed to one space, then trimmed and lowercased. Unique per user. `save_flashcard` stores word, translation and tag names normalised the same way.                                                                                                                                                                                               | S-01, S-04, S-09       |
| `public.save_flashcard(p_word, p_translation, p_additional_meanings, p_example_sentence, p_cefr, p_tag_names)` | function | Returns `(flashcard_id, created)`; at most 20 tags per call. Inserts the card or finds the existing one by `word_key` (content left unchanged), creates missing tags, links them — one transaction, `security invoker`, `authenticated` only.                                                                                                                                                                                                         | S-01, S-04             |
| `public.proposal_outcomes`                                                                                     | table    | One row per reviewed AI proposal, append-only. Columns: `set_id` (one per accept call), `word` (final word if accepted, AI original if rejected), `word_key` (generated, same rule as `flashcards.word_key`, not unique), `outcome`, `merged` (accepted into an existing card), `model`, `tag_name`, `created_at`. Index on `(user_id, word_key)`.                                                                                                    | S-03, S-07, S-09       |
| `proposal_outcomes.outcome` values                                                                             | enum     | `accepted_unchanged`, `accepted_corrected`, `rejected_wrong`, `rejected_known`, `rejected_too_easy` (check constraint). `rejected_too_easy` is produced by S-03's bulk reject ("Odrzuć wszystkie jako Za łatwe").                                                                                                                                                                                                                                     | S-01, S-03, S-07, S-09 |
| `public.accept_proposal_set(p_tag_name, p_model, p_items)`                                                     | function | `p_items`: jsonb array of 1–150 `{ word, translation, additionalMeanings, exampleSentence, cefr, outcome }`. Accepted items go through `save_flashcard` with the one tag; every item gets an outcome row with a shared `set_id` and `merged = not created`. Returns `(created_count, merged_count, rejected_count)`; error `22023` for a bad item count, a blank tag or an unknown outcome. All or nothing, `security invoker`, `authenticated` only. | S-01, S-02, S-03       |
| `public.profiles`                                                                                              | table    | One settings row per user; `user_id` is the primary key (defaults to `auth.uid()`, cascades on user delete). Columns: `cefr_level` (A1–C2 or null), `ai_model` (1–100 chars or null; not constrained to a list — the app validates it against `src/lib/ai/models.ts`), `updated_at`.                                                                                                                                                                  | S-03, S-04             |
| RLS                                                                                                            | policies | Every table: `select` / `insert` / `update` / `delete` for `authenticated` with `user_id = auth.uid()` (`flashcard_tags`: no update; `proposal_outcomes`: select and insert only; `profiles`: select, insert and update, no delete). No policies for `anon` (sees 0 rows).                                                                                                                                                                            | all slices             |

## Service (`src/lib/services/flashcards.service.ts`)

| Name                                                             | Contract                                                                                                                                                 | Relied on by |
| ---------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------ |
| `saveFlashcard(client, input)`                                   | `SaveFlashcardInput` → `{ id, created }`; existing word only gains the tags (FR-005).                                                                    | S-01, S-04   |
| `listFlashcards(client)`                                         | `Flashcard[]` with tags, newest first. **No paging: PostgREST `max_rows` cuts the result at 1,000 rows without an error** — S-05 adds `.range()` paging. | S-05         |
| `updateFlashcard(client, id, patch)`                             | Content only; `DuplicateWordError` on word collision, `FlashcardNotFoundError` if not visible.                                                           | S-05         |
| `deleteFlashcard(client, id)`                                    | Removes the card and its links; tags stay.                                                                                                               | S-05         |
| `suggestTags(client, prefix?)`                                   | Up to 20 of the user's tags by name, prefix matched on `name_key`.                                                                                       | S-01, S-05   |
| `Flashcard`, `Tag`, `SaveFlashcardInput`, `UpdateFlashcardInput` | Shared types in `src/types.ts`.                                                                                                                          | all slices   |
